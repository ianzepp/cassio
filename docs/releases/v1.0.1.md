# Cassio v1.0.1

Fix missing human messages in Codex conversation exports.

- Read user text from Codex `response_item` messages as well as legacy
  `event_msg` user events, restoring both readable transcripts and training JSON.
- Count duplicate representations once, preserving both source references in
  training exports. Keep repeated prompts and sessions that mix log formats.
- Exclude injected instructions, environment context, and agent notifications
  from human conversation text.

Existing exports need regeneration with `--force` against their original session
logs to recover the missing messages. Installing the update alone does not
regenerate the archive.
